# Todo 완료 상태 필터 명세

## 목적

사용자가 전체 Todo 중에서 진행 중인 항목이나 완료된 항목만 빠르게 확인할 수 있게 합니다.

## 범위

- Todo 목록에 `전체`, `진행 중`, `완료` 필터를 제공합니다.
- 앱을 처음 열거나 새로고침하면 `전체`를 기본값으로 선택합니다.
- 필터 선택 상태는 브라우저 저장 대상에 포함하지 않습니다.
- 선택한 필터에 따라 목록에 표시할 Todo만 변경합니다. 저장된 Todo 데이터와 완료 상태는 변경하지 않습니다.

## 동작

| 선택한 필터 | 표시할 Todo |
|---|---|
| 전체 | 완료 여부와 관계없이 모든 Todo |
| 진행 중 | 완료되지 않은 Todo만 |
| 완료 | 완료된 Todo만 |

- 사용자가 필터를 선택하면 목록을 즉시 갱신합니다.
- 현재 선택된 필터를 사용자가 구분할 수 있게 표시합니다.
- 선택한 조건에 해당하는 Todo가 없으면 빈 목록을 표시합니다.
- 필터가 선택된 상태에서 Todo의 완료 여부가 바뀌면 현재 조건에 맞게 목록을 즉시 갱신합니다.
- 필터가 선택된 상태에서 Todo를 추가하거나 삭제하면 현재 조건을 유지한 채 목록을 갱신합니다.

## 기존 기능 유지

- Todo 추가 기능을 유지합니다.
- Todo 완료 및 미완료 전환 기능을 유지합니다.
- Todo 삭제 기능을 유지합니다.
- 브라우저 저장 및 불러오기 기능을 유지합니다.
- 남은 Todo 개수는 필터와 관계없이 전체 Todo를 기준으로 계산합니다.

## 제외 범위

- 필터 선택 상태 저장
- URL 쿼리 또는 경로와 필터 상태 연동
- 검색, 정렬, 카테고리 기능
- 필터별 Todo 개수 표시
- 빈 목록 전용 안내 문구 추가

## 완료 조건

1. 앱을 처음 열거나 새로고침하면 `전체`가 선택되고 모든 Todo가 표시됩니다.
2. `진행 중`을 선택하면 미완료 Todo만 표시됩니다.
3. `완료`를 선택하면 완료 Todo만 표시됩니다.
4. `전체`를 다시 선택하면 모든 Todo가 표시됩니다.
5. 선택된 필터를 화면에서 구분할 수 있습니다.
6. 필터 사용 중 Todo를 추가하거나 완료 상태를 전환하거나 삭제해도 현재 필터가 유지되며 목록이 조건에 맞게 갱신됩니다.
7. 필터를 바꿔도 저장된 Todo와 각 Todo의 완료 상태는 변경되지 않습니다.
8. 남은 Todo 개수는 어떤 필터를 선택해도 전체 Todo의 미완료 항목 수를 표시합니다.
