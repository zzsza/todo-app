# Todo 제목 검색 기능 명세

## 목적

Todo가 많아졌을 때 사용자가 제목으로 필요한 Todo를 빠르게 찾을 수 있게 합니다.

## 기능 범위

- Todo 추가 영역과 목록 사이에 검색창 하나를 표시합니다.
- 사용자가 검색창에 입력하면 별도 제출 없이 목록을 즉시 필터링합니다.
- Todo 제목에 검색어가 포함된 항목만 표시합니다.
- 영문 대소문자를 구분하지 않습니다.
- 검색어 앞뒤의 공백은 검색 조건에서 제외합니다.
- 검색어가 비어 있거나 공백뿐이면 전체 Todo를 표시합니다.
- 일치하는 Todo가 없으면 `검색 결과가 없어요.`라는 빈 상태를 표시합니다.

## 데이터 및 기존 기능

- 검색어는 화면 상태로만 사용하며 `localStorage`에 저장하지 않습니다.
- 검색은 Todo를 추가, 수정 또는 삭제하지 않습니다.
- 검색 중에도 표시된 Todo의 완료/미완료 전환과 삭제 기능은 그대로 동작합니다.
- 남은 할 일 개수는 검색 결과가 아닌 전체 Todo를 기준으로 표시합니다.
- 기존 Todo 추가, 저장 및 최초 로드 동작을 유지합니다.

## 제외 범위

- 완료 여부에 따른 필터링
- 검색어 강조 표시
- 검색 기록 또는 검색어 저장
- 초성 검색, 유사어 검색 및 오타 보정
- 제목 외 속성 검색

## 완료 조건

1. Todo 제목의 일부를 입력하면 해당 문자열을 포함한 Todo만 즉시 표시됩니다.
2. 영문 검색어의 대소문자가 달라도 일치하는 Todo가 표시됩니다.
3. 검색어 앞뒤에 공백이 있어도 공백을 제외한 검색어로 필터링됩니다.
4. 검색어를 모두 지우거나 공백만 입력하면 전체 Todo가 다시 표시됩니다.
5. 일치하는 Todo가 없으면 검색 결과 전용 빈 상태가 표시됩니다.
6. 검색 결과에 표시된 Todo를 완료 처리하거나 삭제하면 해당 동작이 저장 데이터에 반영됩니다.
7. 검색 중에도 남은 할 일 개수는 전체 Todo의 미완료 항목 수를 표시합니다.
8. 검색 기능을 사용한 뒤에도 Todo 추가, 완료/미완료 전환, 삭제 및 브라우저 저장 기능이 기존과 동일하게 동작합니다.
