# 우선순위 기능 명세

## 문서 정보

- 상태: 구현 전 확정본
- 작성일: 2026-09-15
- 대상: `day06/todo-app`
- 근거 문서: `docs/PRD.md`, `AGENTS.md`

## 목적

사용자가 여러 할 일 중 중요한 일을 바로 구분할 수 있게 합니다. 기존 Todo 추가, 완료 전환, 삭제, 저장과 남은 개수 확인 기능은 그대로 유지합니다.

## 사용자 결정

- 우선순위는 `높음`, `보통`, `낮음` 3단계입니다.
- 새 할 일의 기본 우선순위는 `보통`입니다.

## 이번 구현 범위

1. 새 할 일을 추가할 때 우선순위를 선택할 수 있습니다.
2. 각 할 일에 현재 우선순위를 글자로 표시합니다.
3. 추가한 뒤에도 각 할 일의 우선순위를 바꿀 수 있습니다.
4. 바꾼 우선순위는 브라우저 저장소에 즉시 저장합니다.
5. 새로고침해도 우선순위가 유지됩니다.
6. 기존에 저장된 할 일에 우선순위 정보가 없으면 `보통`으로 처리합니다.

## 화면 구성

### 할 일 입력 영역

- 기존 할 일 입력칸 옆에 우선순위 선택 항목을 둡니다.
- 선택지는 `높음`, `보통`, `낮음` 순서로 표시합니다.
- 첫 화면과 할 일 추가 직후의 선택값은 `보통`입니다.
- 모바일 화면에서는 입력칸, 우선순위 선택, 추가 버튼을 세로로 배치할 수 있습니다.

### 할 일 목록

- 각 할 일에 우선순위를 글자로 표시합니다.
- 색상은 구분을 돕는 보조 수단으로만 사용합니다. 색상만으로 우선순위를 표현하지 않습니다.
- 우선순위 선택 항목에는 어떤 할 일의 우선순위인지 알 수 있는 설명을 제공합니다.
- 우선순위를 바꿔도 목록의 입력 순서는 유지합니다.
- 완료 표시와 삭제 버튼의 현재 동작은 유지합니다.

## 데이터 규칙

할 일 한 개는 다음 정보를 가집니다.

```text
id: 할 일을 구분하는 값
title: 할 일 내용
completed: 완료 여부
priority: high | medium | low
```

화면 표시와 저장값의 대응은 다음과 같습니다.

| 화면 표시 | 저장값 |
|---|---|
| 높음 | `high` |
| 보통 | `medium` |
| 낮음 | `low` |

- 우선순위 값이 없거나 허용되지 않은 값이면 `medium`으로 처리합니다.
- 기존 저장 자료를 읽을 때 제목, 완료 여부와 식별값은 변경하지 않습니다.

## 세부 동작

### 할 일 추가

1. 사용자가 할 일과 우선순위를 선택합니다.
2. `추가` 버튼을 누르거나 입력칸에서 Enter 키를 누릅니다.
3. 새 할 일이 목록 맨 위에 나타납니다.
4. 선택한 우선순위가 새 할 일에 표시됩니다.
5. 남은 할 일 개수가 1 증가합니다.
6. 입력칸을 비우고 우선순위 선택을 `보통`으로 되돌립니다.

공백만 입력하면 할 일을 추가하지 않습니다.

### 우선순위 변경

1. 사용자가 목록에 있는 할 일의 우선순위를 바꿉니다.
2. 해당 할 일의 표시가 즉시 바뀝니다.
3. 변경 결과를 브라우저 저장소에 즉시 저장합니다.
4. 목록 순서, 완료 여부와 남은 할 일 개수는 바뀌지 않습니다.

### 기존 기능과의 관계

- 완료 전환은 우선순위를 보존합니다.
- 할 일 삭제는 해당 할 일의 우선순위도 함께 제거합니다.
- 남은 개수는 완료하지 않은 할 일만 셉니다. 우선순위는 계산에 영향을 주지 않습니다.

## 이번 범위에서 제외하는 기능

- 우선순위에 따른 자동 정렬
- 우선순위별 필터
- 우선순위별 남은 개수
- 검색, 마감일과 할 일 내용 수정
- 사용자가 우선순위 단계를 추가하거나 이름을 바꾸는 설정

## 완료 조건

다음 항목을 실제 브라우저에서 모두 확인하면 구현이 완료된 것으로 판단합니다.

1. `높음`을 선택하고 `보고서 제출`을 추가하면 목록 맨 위에 `보고서 제출`과 `높음`이 표시됩니다.
2. 우선순위를 선택하지 않고 `이메일 답장`을 추가하면 `보통`이 표시됩니다.
3. `보고서 제출`의 우선순위를 `낮음`으로 바꾸면 표시가 즉시 바뀌고 목록 순서는 유지됩니다.
4. 새로고침한 뒤에도 두 할 일의 우선순위가 유지됩니다.
5. 우선순위를 바꿔도 완료 여부와 남은 할 일 개수는 바뀌지 않습니다.
6. 완료 전환 후에도 해당 할 일의 우선순위가 유지됩니다.
7. 할 일을 삭제하면 해당 항목만 사라지고 다른 할 일의 우선순위는 유지됩니다.
8. 우선순위 정보가 없는 기존 저장 자료가 오류 없이 열리고 `보통`으로 표시됩니다.
9. 키보드만 사용해 할 일 입력, 우선순위 선택, 추가와 기존 항목의 우선순위 변경을 수행할 수 있습니다.
10. 작은 화면에서 입력 영역과 할 일 항목이 겹치거나 잘리지 않습니다.

## 구현 예정 파일

- `index.html`: 우선순위 선택 화면 요소를 추가합니다.
- `style.css`: 우선순위 표시와 작은 화면 배치를 추가합니다.
- `app.js`: 우선순위 생성, 변경, 저장과 기존 자료 호환 처리를 추가합니다.
